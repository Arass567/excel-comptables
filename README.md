Fichiers qui accompagnent le livre **« Excel pour Comptables : 150 Formules et Modèles Prêts à l'Emploi »** (Assani Raffion, édition 2026), disponible sur Amazon en ebook Kindle et en broché.

Chaque modèle reprend exactement la structure décrite dans le chapitre correspondant (mêmes feuilles, mêmes cellules, mêmes formules), avec un jeu de données fictif pour l'explorer immédiatement.

Compatible Excel 2016 / 2019 / 2021 / Microsoft 365 et LibreOffice Calc.
