# Excel pour Comptables — Fichiers d'accompagnement

Fichiers qui accompagnent le livre **« Excel pour Comptables : 150 Formules et Modèles Prêts à l'Emploi »** (Assani Raffion, 2ᵉ édition revue et corrigée), disponible sur Amazon en ebook Kindle et en broché.

## 📦 Télécharger tout le dossier

**[⬇️ excel-comptables-fichiers.zip](https://github.com/Arass567/excel-comptables/raw/main/excel-comptables-fichiers.zip)**

## Contenu

| Fichier | Chapitre |
|---|---|
| `00_Classeur_de_reference_150_formules.xlsx` | Annexes A et C : fiche de référence de 147 fonctions + glossaire FR/EN de 146 fonctions |
| `01_Plan_de_tresorerie_previsionnel.xlsx` | 15.1 |
| `02_Balance_agee_clients.xlsx` | 15.2 |
| `03_Rapprochement_bancaire_multi_comptes.xlsx` | 15.3 (pointage ligne à ligne sur plusieurs comptes) |
| `04_Immobilisations_et_amortissements.xlsx` | 15.4 |
| `05_Bilan_et_compte_de_resultat.xlsx` | 15.5 |
| `LISEZ-MOI.txt` | Notes d'utilisation |

Chaque modèle reprend la démarche décrite dans le chapitre correspondant, avec un jeu de données fictif que vous remplacez par le vôtre. Les classeurs sont écrits pour Excel sous Windows (2016 et versions ultérieures) et ont été recalculés dans LibreOffice Calc.

## Historique

- **2ᵉ édition** : les six classeurs ont été corrigés et vérifiés par recalcul (compteur du pointage bancaire, amortissement dégressif, cessions, bilan avec crédit de TVA, formats de nombres). Les modèles 03 et 04, retirés temporairement le 31/10/2026, sont de retour.

Les règles fiscales et comptables, les taux et les seuils changent : vérifiez toujours les valeurs en vigueur sur les sources officielles (impots.gouv.fr, BOFiP, Autorité des normes comptables).
